# 🪱 Tapeworm Message Extractor

A simple data extraction pipeline for **Rubika channels** that collects messages, uses **qwen3:4b through Ollama** to extract structured product information, and stores the results in a database.

## ✨ Overview

Tapeworm consists of two main components:

1. **Rubikaworm** — Scrapes recent messages from Rubika channels and saves them as JSON.
2. **Inserter** — Processes the extracted messages with DeepSeek, converts them into structured data, and inserts the results into a database.

### 🔄 Workflow

```text
Rubika Channels
      │
      ▼
 ┌─────────────┐
 │ Rubikaworm  │
 └─────────────┘
      │
      │ rubika_messages.json
      ▼
 ┌─────────────┐
 │  Inserter   │
 └─────────────┘
      │
      │ Ollama API
      ▼
 Structured Product Data
      │
      ▼
   Database
```

---

# 1. 🪱 Rubikaworm

`Rubikaworm` reads a list of Rubika channel IDs/usernames, fetches their latest messages, and stores the extracted information in a JSON file.

### What it extracts

For each channel, it fetches the **last 50 messages** and stores:

* 💬 Message text
* 🖼️ Image captions
* 🕐 Timestamps
* 📺 Channel information

The result is saved to:

```text
rubika_messages.json
```

## Requirements

Install [`rubpy`](https://github.com/Matin-Robati/Rubpy) and the other ones listed in requirements.txt:

```bash
pip install -r requirements.txt
```

## 🔐 Authentication

Rubika's channel-reading API requires an authenticated user session. There is no public read-only API for arbitrary channel history.

The first time you run the script, `rubpy` will ask for:

1. Your phone number
2. The login code sent to your Rubika application

After successful authentication, a session file such as:

```text
my_session.session
```

will be saved in the same directory.

You won't need to log in again on future runs unless the session expires or is removed.

## 🚀 Usage

### 1. Add channels

Create or edit:

```text
rubika_channels.txt
```

Add one channel per line.

You can use either public channel usernames:

```text
my_channel
@my_channel
```

or channel GUIDs:

```text
c0xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 2. Run Rubikaworm

```bash
python rubikaworm.py
```

### 3. Check the output

The extracted messages will be written to:

```text
rubika_messages.json
```

# 2. 📦 Inserter

`Inserter` takes the messages collected by Rubikaworm, sends them to **ollama**, extracts structured product information, and stores the results in the database.

## Requirements

Make sure you have:

* [.NET 10](https://dotnet.microsoft.com/) and ollama installed
* qwen3:4b model downloaded
* A database and connection string
* `rubika_messages.json` generated by Rubikaworm

## ⚙️ Configuration

Configure the application using `appsettings.json` or **.NET User Secrets**.

Example:

```json
{
  "ConnectionStrings": {
    "AppDbContext": "your-connection-string-here"
  },
  "Ollama": {
    "BaseAddress": "localhost:11434",
    "model": "qwen3:4b"
  },
  "MessagesFilePath": "path/to/rubika_messages.json"
}
```


## ▶️ Running the Inserter

Start the .NET application:

```bash
dotnet run
```

Once the application is running, use the following endpoints.

### Insert products

Send a request to:

```http
GET /Products/Insert
```

For example:

```text
http://localhost:5010/Products/Insert
```

This endpoint:

1. Reads the extracted Rubika messages.
2. Sends the relevant content to ollama.
3. Extracts structured product information.
4. Saves the results to the database.
